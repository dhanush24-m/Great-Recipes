# 🍳 Great Recipes

A web application to discover, browse, and save your favorite recipes. Built with JavaScript for a smooth and interactive cooking experience.

## 🎯 Features
- 🔍 Search recipes by name or ingredient
- 📋 Browse recipe categories
- 🧑‍🍳 View detailed cooking instructions & ingredients
- ❤️ Save favorite recipes
- 📱 Responsive design for mobile & desktop

## 🛠️ Tech Stack
- **HTML5** — Structure
- **CSS3** — Styling & responsive layout
- **JavaScript** — Interactivity & dynamic content
- **Recipe API** — External recipe data (e.g., TheMealDB / Spoonacular)

## 📂 Project Structure
```
Great-Recipes/
├── index.html          # Main entry point
├── css/
│   └── style.css       # Styling
├── js/
│   └── app.js          # Main JavaScript logic
└── assets/             # Images & icons
```

## 🏃 Getting Started
```bash
# Clone the repo
git clone https://github.com/dhanush24-m/Great-Recipes.git
cd Great-Recipes

# Open in browser
open index.html
```

> **Note:** If using an external API, add your API key in `js/app.js`.
